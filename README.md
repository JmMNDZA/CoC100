# A Call of Cthulu Character Creation and Sheet Manager with Integration to Roll20
## Features

- Robust and easy to use user-interface for new and old players of Call of Cthulu.
- Automated stats alongside character creation.
- Save and load your characters to a JSON file.
- Dice Roller integrated with Roll20.
- Light and Dark interfaces
